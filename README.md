### Sobre mí

Soy desarrollador full stack en Montevideo, Uruguay. Dirijo **[Buyar Services](https://buyarservices.com)**, una agencia de desarrollo web y software a medida, y desde ahí construyo tanto proyectos para clientes como una familia de productos propios en producción.

Trabajo multi-tenant real (un mismo stack sirviendo decenas de tiendas/sitios de clientes distintos) y acompaño todo el ciclo: diseño, backend, frontend, infraestructura y soporte.
