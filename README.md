### 👋 Sobre mí

Soy desarrollador full stack en Montevideo, Uruguay. Dirijo **[Buyar Services](https://buyarservices.com)**, una agencia de desarrollo web y software a medida, y desde ahí construyo tanto proyectos para clientes como una familia de productos propios en producción.

- 🛠️ Stack principal: **Laravel + PHP**, Blade/Tailwind, bases de datos relacionales, Docker para el entorno local.
- 🧩 Trabajo multi-tenant real: un mismo stack sirviendo decenas de tiendas/sitios de clientes distintos.
- 🚀 De la idea al deploy: diseño, backend, frontend, infraestructura y soporte — todo el ciclo.

---

### 🏢 Buyar Services — productos propios

| Producto | Qué es |
|---|---|
| 🛍️ **[MostraloWeb](https://mostraloweb.com)** | Constructor de tiendas online + marketplace multi-tenant |
| 💰 **[Hivault](https://hivault.buyarservices.com)** | App de finanzas personales (web + Android) |
| 🔐 **[Lockar](https://lockar.buyarservices.com)** | Gestor de contraseñas self-hosted, cifrado zero-knowledge |
| 📅 **Turnar** | Sistema de turnos, se instala por cliente |
| 🎮 **[Buyar Games](https://games.buyarservices.com)** | Hub de juegos web (motor Godot) |

Además administramos el panel interno y el portal de clientes de la agencia (gestión, tickets, facturación).
